# OpenSCAD — Versión personalizada

¡Bienvenido a mi fork de OpenSCAD!

Desde hace varios años, esta versión incorpora una nueva funcionalidad: `helicoidal_extrude()`.

No estoy muy familiarizado con Git, ya que durante mi vida profesional trabajé principalmente con Mercurial.

También soy consciente de que `helicoidal_extrude()` tiene una gran cantidad de parámetros, quizá demasiados para incorporarla al software principal.

He ido actualizando regularmente mi versión para mantenerla lo más alineada posible con la rama `master`. Ahora que estoy jubilado, dispongo de más tiempo para dedicar a este proyecto. Por ello, hace poco también empecé a trabajar en un fork de PythonSCAD, con el objetivo de implementar allí `helicoidal_extrude()`.

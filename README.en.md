# OpenSCAD — Customized Version

Welcome to my fork of OpenSCAD!

For several years now, this version has included a new feature: `helicoidal_extrude()`.

I am not very familiar with Git, as I primarily worked with Mercurial during my professional career.

I am also aware that `helicoidal_extrude()` has a very large number of parameters, perhaps too many for it to be included in the core software.

I have regularly updated my version to keep it as closely aligned as possible with the `master` branch. Now that I am retired, I have more time to dedicate to this project. I have therefore also recently started working on a fork of PythonSCAD, with the aim of implementing `helicoidal_extrude()` there as well.

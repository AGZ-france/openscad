# OpenSCAD — Version personnalisée

Bienvenue dans mon fork d'OpenSCAD !

Cette version propose depuis quelques années une nouvelle fonctionnalité helicoidal_extrude().  
Je ne maitrise pas l'outil git, car j'ai essentiellement travaillé avec mercurial lorsque j'étais en activité.  
J'ai conscience également que helicoidal_extrude() possède de très nombreux paramètres, peut être trop pour être ajouté au logiciel de base.  
J'ai régulièrement fait évolué ma version afin de coller au plus près de la branche master, et maintenant que je suis à la retraite, je peux faire d'avantage, et j'ai donc aussi depuis peux entrepris de cloner aussi pythonscad afin d'y implémenter helicoidal_extrude().

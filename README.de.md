# OpenSCAD — Angepasste Version

Willkommen bei meinem Fork von OpenSCAD!

Diese Version bietet seit mehreren Jahren eine neue Funktion: `helicoidal_extrude()`.

Ich bin mit Git nicht besonders vertraut, da ich während meines Berufslebens hauptsächlich mit Mercurial gearbeitet habe.

Mir ist auch bewusst, dass `helicoidal_extrude()` sehr viele Parameter besitzt, möglicherweise zu viele, um in die offizielle Software aufgenommen zu werden.

Ich habe meine Version regelmäßig weiterentwickelt, um sie so eng wie möglich am aktuellen Stand des `master`-Branches auszurichten. Seit ich im Ruhestand bin, habe ich mehr Zeit, mich diesem Projekt zu widmen. Deshalb habe ich vor Kurzem auch damit begonnen, PythonSCAD zu forken, um dort ebenfalls `helicoidal_extrude()` zu implementieren.
